# IUInWeb — mockup histórico

Interfaz experimental diseñada para servirse desde LittleFS en el ESP32. Se
conserva completa, junto con sus librerías y archivos comprimidos, pero no es el
HMI activo. El HMI soportado vive en `desktop_app/` y se ejecuta en la PC.

`comprimir_assets.ps1` regenera los `.gz` dentro de `data/` únicamente para
investigación del mockup.
