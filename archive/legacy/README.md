# Legado

- `IUInWeb/`: mockup web pensado para ejecutarse desde LittleFS en el ESP32.
- `architecture_v2/`: propuesta modular anterior a la aplicación Python actual.
- `hmi_flask_simple/`: interfaz Flask simplificada sustituida por el HMI completo.
- `generadores/` y `generados/`: herramientas y snapshots históricos tipo sopa.

Nada de este directorio participa en compilaciones o empaquetados normales.
Se conserva como referencia y no es una segunda implementación soportada.
